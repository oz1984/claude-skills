# uni-application-prep

Researches CS / software-engineering bachelor's programmes in **Berlin, Munich, Warsaw and Amsterdam**, filters them to the applicant's career goals (AI systems engineering → data & distributed systems → AI security), and prepares a ready-to-submit application pack for each shortlisted programme.

## What it produces

1. A comparison table — programme, city, intake, deadline, tuition, requirement gaps, fit score, sources.
2. A realistic shortlist of 3–6 programmes, one-line reason each.
3. Per shortlisted programme: a programme-specific motivation-letter draft (from the user's real experiences only), a document checklist, a deadline calendar, exact portal steps, and a pre-filled form-field sheet.

## Hard rules

- **Stops at the submit button.** Never submits, creates portal accounts, pays fees, or enters personal data.
- **Every fact links to an official page.** Anything that can't be verified is marked `unverified` — deadlines, fees and requirements are never invented.
- **No invented achievements**, no template letters with the name swapped, and no AI-detector-evasion rewrites.
- Covers the Syrian secondary certificate route: recognition body, Studienkolleg / foundation year, uni-assist / APS / Studielink / IRK, and visa timelines.

## Install

```bash
/plugin install uni-application-prep@claude-code-skills
```

Then ask: *"Find CS bachelor's programmes in Berlin and Amsterdam that fit my goals and prepare the applications."*
